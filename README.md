# GuignaLabs Organization Repository

This repository contains organization-level GitHub material and contributor
guidance. Application source and internal company records belong to their own
repositories.

- [Organization profile](profile/README.md): the profile content.
- [Contributor instructions](AGENTS.md): repository conventions and Gitflow.
- [Shared workflow](.workspace/workflow.md): portable delivery instructions.
- [Task template](.workspace/templates/task.md): bounded work and handoff records.

There is no application runtime or build here. Review Markdown links and preview
content before publishing. Use `git diff --check` and `git diff --cached --check`
to inspect whitespace in working and staged changes.
